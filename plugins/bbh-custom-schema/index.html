Overview

Why BBH Custom Schema?

It works alongside your existing SEO plugins without breaking them, and includes built-in validation to catch errors before they go live.

Installation

Get Started in Minutes

Two simple ways to install BBH Custom Schema on your WordPress site.

Via WordPress Admin

  1. Go to Plugins → Add New in your WordPress dashboard
  2. Search for BBH Custom Schema
  3. Click Install Now
  4. Click Activate
  5. You will see a new Custom Schema section in the post editor

Manual Upload

  1. Download the plugin zip from WordPress.org
  2. Go to Plugins → Add New → Upload Plugin
  3. Choose the downloaded bbh-custom-schema.1.4.0.zip file
  4. Click Install Now then Activate
  5. Start adding schema from the post editor sidebar
Usage

How to Add Custom Schema

Adding structured data to your content takes just a few steps — no coding knowledge required beyond basic JSON.

1

Edit a Post or Page

Open any post, page, or custom post type in the WordPress block editor (Gutenberg) or classic editor.

2

Expand the Custom Schema Section

In the editor sidebar, look for the Custom Schema meta box. Expand it to reveal the JSON-LD text area.

3

Paste or Write Your JSON-LD

Enter valid JSON-LD markup for your desired schema type. For example, an Article schema:

{ "@context": "https://schema.org", "@type": "Article", "headline": "Your Title", "author": { "@type": "Person", "name": "Author Name" } }

4

Validate Your Schema

Click the Validate button to check for JSON syntax errors. The plugin highlights issues so you can fix them before publishing.

5

Combine Multiple Schemas (Optional)

If you need multiple schema types on the same page, add each block separately. The Schema Combiner auto-merges them into a single @graph structure.

6

Publish and Verify

Update or publish your post. Your JSON-LD schema renders in the <head>. Use the Rich Results Test or Schema.org Validator to confirm it works.

FAQ

Frequently Asked Questions

Common questions about structured data, schema markup, and the BBH Custom Schema plugin.

What is schema markup and why does it matter?

Schema markup is structured data you add to your website to help search engines understand your content better. It can enable rich results like star ratings, FAQs, breadcrumbs, and product details in search engine results pages (SERPs).

Do I need coding knowledge to use this plugin?

Basic familiarity with JSON syntax is helpful but not required. The plugin includes built-in JSON validation that catches errors, and you can find ready-to-use schema templates online. The Quick Start onboarding also guides first-time users through the process.

Will this plugin slow down my website?

No. BBH Custom Schema is exceptionally lightweight. It adds no front-end JavaScript, no external HTTP requests, and only runs the minimal PHP needed to render your JSON-LD in the page head. There is zero impact on page load speed.

Is it compatible with Yoast, Rank Math, or other SEO plugins?

Yes. BBH Custom Schema works alongside any SEO plugin without conflict. You can use it to override, supplement, or replace the auto-generated schema from other plugins while keeping their other SEO features active.

How can I check whether my schema is working?

After publishing, use Google Rich Results Test, Schema.org Validator, or the URL Inspection Tool in Google Search Console. These tools will parse your page and display any structured data found in the source.

Can I use multiple schema types on the same page?

Absolutely. The plugin supports adding multiple JSON-LD blocks per page. The Schema Combiner feature automatically merges them into a single valid @graph structure that follows schema.org best practices.

Does the plugin auto-generate schema for my content?

No. BBH Custom Schema is a manual tool — it does not auto-generate any markup. You provide your own JSON-LD. This gives you complete control and avoids the duplicate and incorrect schema that auto-generation often produces.

What schema types are supported?

All schema.org types are supported. As long as you supply valid JSON-LD, the plugin will render it. Common types include Article, Product, FAQPage, LocalBusiness, Service, Event, Recipe, Review, VideoObject, and SoftwareApplication.
