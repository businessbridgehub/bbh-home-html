Overview

What Is BBH Security Insight?

BBH Security Insight is a free, lightweight WordPress plugin that performs a comprehensive, read-only security audit of your WordPress installation. It checks 15 critical security areas — from WordPress version exposure and database table prefixes to security headers and malware heuristics — then presents the results in a beautiful, color-coded Security Risk Report with an overall score out of 100, clear risk indicators, and actionable remediation advice.

This plugin is designed for site owners, developers, and agencies who want a fast, non-intrusive way to identify potential security weaknesses in their WordPress sites. It never modifies files, never changes settings of your site, and never sends data to external servers. Just click, scan, and review.

Audit Checks

15 Security Checks

BBH Security Insight evaluates your site across 15 carefully selected security parameters covering exposure, configuration, file permissions, and code integrity.

WordPress Version Exposure

Checks whether your WordPress version is publicly visible in the page source, which can help attackers target known vulnerabilities.

Database Table Prefix

Verifies that the default wp_ prefix has been changed to reduce the risk of SQL injection attacks on your database.

XML-RPC Status

Detects whether XML-RPC is enabled, which can be abused for brute-force attacks and DDoS amplification if not properly secured.

DISALLOW_FILE_EDIT

Confirms whether the constant DISALLOW_FILE_EDIT is defined in wp-config.php to prevent in-dashboard file editing.

WP_DEBUG Status

Verifies that WP_DEBUG is disabled on production sites so sensitive error information is not exposed to visitors.

Directory Browsing

Tests whether directory listing is enabled on key directories, which can expose the full file structure of your site to attackers.

readme.html Exposure

Checks if the WordPress readme.html file is accessible, revealing your WordPress version and installation path.

install.php Exposure

Verifies that wp-admin/install.php is not accessible, which could allow a fresh installation to be triggered.

wp-config.php Permissions

Checks the file permissions on wp-config.php to ensure it is not world-readable, protecting your database credentials.

wp-content Permissions

Verifies that the wp-content directory has secure permissions and is not writable by unauthorized users.

User Enumeration Exposure

Tests whether usernames can be enumerated via REST API or author archives, which is a common first step in targeted attacks.

Security Headers

Checks for the presence of critical HTTP security headers including CSP, HSTS, X-Frame-Options, X-Content-Type-Options, and Referrer-Policy.

Uploads PHP Execution

Verifies that PHP execution is blocked in the wp-content/uploads directory to prevent uploaded malicious files from running.

Admin Username Detection

Checks whether the default admin username exists, which is an easy target for brute-force login attempts.

Malware Heuristics

Scans for suspicious code patterns commonly associated with malware, backdoors, and injected payloads using heuristic analysis.

Installation

Get Started in Minutes

Two simple ways to install BBH Security Insight on your WordPress site.

Method 1: From WordPress Dashboard

  1. Go to Plugins → Add New in your WordPress admin.
  2. Search for BBH Security Insight.
  3. Click Install Now and then Activate.
  4. Go to Tools → Security Insight to run your first audit.

Method 2: Manual Upload

  1. Download the plugin zip file from WordPress.org.
  2. Go to Plugins → Add New → Upload Plugin.
  3. Choose the downloaded zip and click Install Now.
  4. Click Activate Plugin and navigate to Tools → Security Insight.

FAQ

Frequently Asked Questions

Common questions about BBH Security Insight answered.

Is BBH Security Insight really read-only?

Yes, completely. The plugin runs checks by reading WordPress configuration constants, checking file permissions, and making safe HTTP requests to your own site. It never modifies files, changes database records, deletes data, or alters any settings. You can run it with complete peace of mind.

Does this plugin send my data anywhere?

No. BBH Security Insight processes everything locally on your server. All audit checks run against your own WordPress installation, and the results are displayed only in your admin dashboard. No data is sent to Business Bridge Hub, WordPress.org, or any third-party service.

How often should I run a security audit?

We recommend running an audit at least once a month, or after any significant change to your site such as updating plugins, changing themes, adding new users, or modifying server configuration. However, there is no restriction from our side — you may run the scan as many times as needed.

Can BBH Security Insight fix security issues?

No. This plugin is intentionally read-only and diagnostic only. It tells you what is wrong and provides clear, step-by-step instructions for how to fix each issue. We believe site owners should make informed decisions about their own security rather than relying on automated fixes that could break functionality.

How accurate is the malware heuristics check?

The malware heuristics check scans for suspicious code patterns commonly found in known malware, backdoors, and injected payloads. It uses signature-based pattern matching and is designed to flag potential threats for manual review. It is not a replacement for a dedicated security plugin but serves as an excellent first line of awareness.

Will this plugin slow down my site?

Not at all. BBH Security Insight only runs when you actively click the Run Security Audit button. It has no background processes, no cron jobs, no database overhead, and no front-end impact. When you are not on the audit page, the plugin does nothing at all.
