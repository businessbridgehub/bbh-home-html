Overview

About BBH Lite

BBH Lite is a lightweight, modern WordPress theme crafted for agencies, freelancers, and site owners who value speed, accessibility, and editorial flexibility. It delivers a clean semantic HTML5 foundation with schema-ready markup, making it an excellent choice for content-driven websites, blogs, and small business sites.

Developed by Md Jahid Shah and maintained by the Business Bridge Hub team, BBH Lite combines a minimal footprint with powerful features — multi-level dropdown navigation, widgetized footer areas, Customizer-driven layout controls, and full compatibility with the WordPress block editor, Elementor, and WooCommerce. Whether you are launching a personal blog or a client project, BBH Lite provides the performance and structure you need out of the box.

Features

What Makes BBH Lite Different

Lightweight Architecture

Weighing in at under 30 KB combined CSS and JavaScript, BBH Lite loads fast on any connection. Every line of code is optimized for performance without sacrificing functionality.

Keyboard-Accessible Navigation

Multi-level dropdown menus built with full keyboard navigation support. Users can tab through menu items, open submenus, and navigate your site without a mouse.

Block Editor & Elementor Compatible

Works seamlessly with the WordPress block editor and Elementor page builder. Create rich layouts with blocks, patterns, and drag-and-drop editing exactly as you envision them.

Customizer Controls

Adjust header layout, footer style, color schemes, and typography directly from the WordPress Customizer. No coding required to make the theme your own.

Schema-Ready Semantic HTML5

Built with accessible, semantic HTML5 elements and schema.org-ready markup. Search engines and assistive technologies can parse your content with clarity.

Translation & RTL Ready

Fully translation-ready with internationalization support and right-to-left (RTL) language compatibility. Reach global audiences without extra development work.

WooCommerce Compatible

Integrates smoothly with WooCommerce for online stores. Product pages, cart, checkout, and shop archives inherit the same clean responsive layout as the rest of your site.

Mobile-First Responsive Design

Every component is built mobile-first, from the collapsible navigation to flexible grid layouts. Your site looks polished on phones, tablets, and desktops alike.

Featured Image Layouts

Choose from multiple featured image placements — full-width banners, side-by-side with post content, or thumbnail grids. Control appearance per post or globally.

Widget Areas

Dedicated widget areas in the footer provide space for custom menus, recent posts, social links, and any other block or widget you want to display site-wide.

Installation

Getting Started

Install via WordPress Dashboard

1

Navigate to Themes

Log in to your WordPress admin panel and go to Appearance → Themes.

2

Add New Theme

Click the Add New button at the top of the Themes page, then use the search field to look for "BBH Lite".

3

Install & Activate

Locate BBH Lite in the search results and click Install. Once the installation finishes, click Activate to start using your new theme.

Manual FTP Installation

1

Download the Theme

Download the BBH Lite zip package from the WordPress.org theme directory or the BBH official site.

2

Extract & Upload

Extract the zip file on your computer. Using an FTP client, upload the extracted bbh-lite folder to /wp-content/themes/ on your server.

3

Activate the Theme

Go to your WordPress admin panel, navigate to Appearance → Themes, find BBH Lite in the list, and click Activate.

Customization

Theme Customization

BBH Lite integrates deeply with the WordPress Customizer, giving you real-time control over your site's appearance without touching a single line of code. From the Customizer, you can adjust the header layout style, select footer widget column arrangements, modify accent and background colors, and manage typography settings. All changes preview live before you publish them.

In addition to Customizer options, BBH Lite ships with several block editor patterns that help you quickly build common page layouts — including hero sections, call-to-action blocks, feature grids, and contact sections. These patterns appear in the block inserter and can be inserted with one click, then customized with your own content and media.

The theme provides three widget areas in the footer, each manageable from Appearance → Widgets. You can populate them with any core WordPress widget or third-party plugin widget, such as recent posts, tag clouds, social media feeds, email subscription forms, or custom navigation menus.

FAQ

Frequently Asked Questions

Is BBH Lite compatible with the latest version of WordPress?

Yes. BBH Lite is tested with WordPress 6.0 and above, including the latest 6.x releases. The theme follows WordPress coding standards and is reviewed during the WordPress.org directory submission process.

Will BBH Lite slow down my website?

No. BBH Lite is engineered for performance with a combined CSS and JavaScript payload under 30 KB. It avoids heavy dependencies, deferred scripts, and follows performance best practices to ensure fast page loads and high Core Web Vitals scores.

Can I customize the colors, fonts, and layout?

Absolutely. BBH Lite exposes header layout, footer layout, color palette, and typography settings through the WordPress Customizer. You can tailor the look of your site in real time without editing any theme files.

Do you offer support for BBH Lite?

Support is available through the WordPress.org support forum for the theme. You can also reach out via the Business Bridge Hub contact page for premium assistance or custom development requests.

Is BBH Lite translation ready? Does it support RTL languages?

Yes. The theme is fully internationalized with translatable strings and includes right-to-left (RTL) stylesheet support. You can use plugins like Loco Translate or Poedit to create translations for any language.

Can I use BBH Lite with WooCommerce?

Yes. BBH Lite includes WooCommerce integration with properly styled product pages, cart, checkout, and shop archives. The responsive layout ensures a consistent shopping experience on every device.
